# VK Mini App

Статический мобильный клиент на нативных ES-модулях, без отдельного runtime и сборщика.

- `index.html` — документ и точки подключения.
- `src/app.js` — bootstrap, делегирование событий и связывание экранов.
- `src/core/` — состояние, API-клиент и VK Bridge.
- `src/components/` — повторно используемые компоненты.
- `src/screens/` — независимые экраны.
- `styles/app.css` — дизайн-токены, компоновка и компоненты.
- `legacy/index.html` — прежняя рабочая реализация на время миграции.

Не дублировать навигацию, API-клиент или бизнес-логику между экранами. Backend остаётся источником истины. Перенос камеры должен сохранить сценарий «съёмка → предпросмотр → переснять/подтвердить → очередь/отправка → следующий номер». Автоматическая отправка при съёмке запрещена.
